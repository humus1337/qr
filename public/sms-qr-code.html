How to make an SMS QR code

  1. Enter the number. Add the phone number the text should go to, in international format.
  2. Prefill the message. Optionally add the text that should already be typed, such as a keyword.
  3. Design it. Add your colors, a gradient, or a logo.
  4. Download. Save PNG or SVG for print or the web.

Turn a scan into a text

An SMS QR code is a neat way to run keyword campaigns without asking people to type your number. Prefill a word like JOIN or VOTE, and a scan opens a message that is ready to send. It works for opt-ins, feedback lines, event check-ins and promotions on posters, packaging and screens.

Questions

What happens when someone scans it?

Their phone opens the messaging app with a new text addressed to your number and any message you set already typed. They tap send.

Does it send the text automatically?

No. It only opens a prefilled draft. The person reviews and sends it themselves.

Is it good for SMS keyword campaigns?

Yes. Prefill a keyword such as JOIN so people can opt in with a scan instead of typing your number and the keyword by hand.

Is it free with no watermark?

Yes. The code is free, has no watermark, and never expires. It is built entirely in your browser.
