Static vs dynamic QR codes

By the DesignYourQR team. Last updated: September 24, 2026.

The short answer: a static QR code stores your content directly in the image and never expires, while a dynamic QR code stores a redirect the provider controls, which you can edit and track but usually have to pay to keep alive. For anything you print, a static code is the safer choice because no company can switch it off later.

When to use each

Use a static code for anything printed or long-lived: menus, business cards, flyers, packaging, signage and product labels. It is free, permanent, and no third party sits between the scan and the destination. Choose a dynamic code only when you genuinely need to change the destination after the code is already printed, or you need built-in scan analytics and are willing to pay to keep the redirect alive.

A middle path without a paid plan

You can get some of the flexibility of a dynamic code while keeping a free static one: point the static code at a link you control, such as a page on your own site or a short link you manage. Change what that link shows and every printed code keeps working, because the code only carries the address, not the content behind it. Keep the link stable and you never reprint.

Questions

What is a static QR code?

A static QR code stores the content, such as a link or text, directly in the pattern of squares. There is no server in the loop, so once the image is saved it works forever and cannot be switched off or edited.

What is a dynamic QR code?

A dynamic QR code stores a short redirect URL that points at a destination the provider controls. That lets you edit the destination and see scan analytics, but it also means the provider can disable it, and keeping it active usually requires a paid plan.

Do static QR codes expire?

No. A static QR code never expires because the content lives inside the image itself with no server involved. A dynamic code can stop working if the provider disables the redirect or the plan lapses.

Can I edit a static QR code after printing?

Not the code itself. But if the static code points at a link you control, such as a page or short link you manage, you can change what that link shows without changing the printed code.

Which should I use for print?

Use a static code for anything you print, such as menus, business cards, flyers and signage, because it cannot expire or be paywalled later. Choose dynamic only if you truly need to edit the destination after printing or need built-in scan analytics.
