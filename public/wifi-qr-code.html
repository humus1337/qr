How to make a Wi-Fi QR code

  1. Enter your network. Type the network name (SSID) exactly as it appears, then the password.
  2. Pick the security type. Choose WPA/WPA2/WPA3 for almost every modern router, WEP for very old ones, or Open network if there is no password. Tick Hidden network if yours does not broadcast its name.
  3. Design it. Add your own colors, a logo, or a Scan to connect label so it looks the part on a table tent or wall.
  4. Download and print. Save PNG or SVG, then place it wherever guests will scan it.

Where a Wi-Fi QR code helps

Cafes and restaurants put one on the table so customers stop asking for the password. Guesthouses and rentals leave one in the room. Offices tape one in the reception area for visitors. At home it saves you reading out a random string of characters every time someone comes over.

Because the network name and password are encoded into the image itself, the code keeps working with no account and no monthly fee. If you change your Wi-Fi password later, just generate a fresh code.

Questions

Does it work on iPhone and Android?

Yes. iPhones on iOS 11 and later and modern Android phones read a Wi-Fi QR code straight from the camera app, then offer to join the network. No separate scanner app is needed.

Is my Wi-Fi password kept private?

Yes. The code is built entirely in your browser. Your network name and password are never uploaded to us or to any server, and the password is stored inside the QR image itself.

Which security type should I choose?

Most home and office routers use WPA, WPA2 or WPA3, so pick WPA. Use WEP only for very old routers, and Open network for a password-free hotspot.

Can I print it for a cafe or guest room?

Yes. Download SVG or a PNG at 2048 px or larger for a crisp print at any size, add a Scan to connect label, and place it on the table, wall or a card.
