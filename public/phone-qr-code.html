How to make a phone QR code

  1. Enter the number. Type it in international format with the country code, for example +1 555 000 1234.
  2. Design it. Add your colors, a gradient, or a logo.
  3. Download. Save PNG or SVG for print or screens.
  4. Place it. Put it on signs, flyers, a menu or a vehicle wrap so people can call in one tap.

Make it easy to call you

A phone QR code removes the friction of copying a number off a poster. Someone points their camera, taps once, and the dialer opens with your number ready. It works well for tradespeople, clinics, taxis, real estate signs and anywhere a quick call is the goal.

Questions

Does scanning it dial automatically?

It opens the phone dialer with your number ready. The person taps the call button to place the call, so nothing dials without them.

What number format should I use?

Use international format with the country code, for example +1 555 000 1234. That way the code works for people calling from anywhere.

Does it work on iPhone and Android?

Yes. Both read a tel QR code from the camera and open the dialer with the number filled in.

Is it free and permanent?

Yes. The number is stored in the image, so the code is free, has no watermark, and never expires.
