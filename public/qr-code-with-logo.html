How to add a logo to a QR code

  1. Enter your content. Add the link or other content the code should carry.
  2. Add your logo. Open the Logo section and drop in a PNG, JPG or SVG. It stays on your device.
  3. Size and clean it. Adjust the logo size and let the tool remove a plain background, or add a backdrop so it sits neatly over the code.
  4. Watch the scan meter. The meter under the preview turns from green to amber if the logo gets too big, so you know before you print.
  5. Download. Save PNG or SVG, with a transparent background if you want one.

Branded, and still scannable

A logo in the center makes a code look like it belongs to you rather than a generic black-and-white square. The trick is error correction: with a logo on, the code carries enough redundancy to recover the area the logo covers, so it keeps reading. The built-in scan meter checks this live and warns you the moment a logo grows large enough to cause trouble.

You can also recolor the code to your brand, use a gradient, and export a transparent PNG or a crisp SVG for print, all with no watermark and nothing sent to a server.

Questions

Will a logo stop it from scanning?

Not if it is kept in check. Error correction rises to High automatically when a logo is on, so the code can lose the covered area and still read. Keep the logo under about 30 percent of the width and watch the scan meter.

What image format should the logo be?

PNG, JPG or SVG all work. A PNG or SVG with a transparent background looks cleanest, and the tool can also knock out a plain background for you.

Is there a watermark on the download?

No. The downloaded code is clean, with no watermark and no label unless you add one yourself. Many other generators stamp free downloads.

Can I use a logo QR code commercially?

Yes. The code is a plain static QR that is yours to use on products, packaging, signage and marketing, at no cost.
