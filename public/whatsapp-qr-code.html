How to make a WhatsApp QR code

  1. Build your wa.me link. Write https://wa.me/ followed by your number in full international format with no plus sign or spaces, for example https://wa.me/15551234567.
  2. Add a message (optional). Append ?text= and a short message so the chat opens ready to send, for example ?text=Hi, I have a question.
  3. Paste and design. Drop the link into the generator and add your colors, a gradient or a logo.
  4. Download and share. Save PNG or SVG and print it on flyers, packaging, a menu or the storefront.

Questions

What link should a WhatsApp QR code use?

Use the wa.me click-to-chat link: https://wa.me/ followed by your phone number in full international format with no plus sign, spaces or dashes, for example https://wa.me/15551234567.

Can I prefill a message?

Yes. Add ?text= and your message to the end of the link, for example https://wa.me/15551234567?text=Hi, so the chat opens with that text ready to send.

Do I need WhatsApp Business?

No. The wa.me link works with any WhatsApp number, personal or Business. When someone scans the code, their phone opens a chat with your number.

Does it work from any phone camera?

Yes. It is a standard QR code to a normal web link, so any modern iPhone or Android camera opens it, then the phone launches WhatsApp.

Is it free and does it expire?

It is a free static QR code with no watermark and no expiry. The link is stored in the image, so it keeps working with no account and no fee.
