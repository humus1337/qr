Embed a free QR code generator on your website

By the DesignYourQR team. Last updated: September 24, 2026.

Paste one line of HTML and your visitors can create and download custom QR codes without leaving your page. There is no API key, no sign-up and no fee. Every code is generated in the visitor's browser, so nothing they type is uploaded.

Live preview and code

Copy this into any HTML block on your site:

<iframe src="https://designyourqr.com/embed" width="100%" height="480" style="border:0;max-width:420px" loading="lazy" title="Free QR code generator by DesignYourQR"></iframe>
<p>Free QR code generator by <a href="https://designyourqr.com" rel="noopener">DesignYourQR</a></p>

Keeping the small credit line is appreciated, and it is a real link back to us.

How to add it

  1. Copy the code above. Use the Copy button.
  2. Paste it into your page. Add it to a Custom HTML or Embed block on WordPress, Wix, Squarespace, Webflow, Notion or a plain HTML page.
  3. Adjust the size. Change the width and height in the code to fit your layout. It is responsive down to about 300 px wide.

Why embed this one

It is free with no API key and no account to manage, so there is nothing to set up or renew. The codes your visitors make are plain static QR codes with no watermark and no expiry, and generation runs entirely in their browser, so you are not routing anyone's links through a third-party server. The widget matches light and dark pages automatically.

Questions

Is the embedded QR code generator free?

Yes. The widget is completely free to embed and to use, with no API key, no sign-up and no usage fee. The QR codes it makes have no watermark and no expiry.

Do I need an API key or account to embed it?

No. You paste one HTML snippet with an iframe. There is nothing to register and no key to manage.

Does it work on WordPress, Wix or Squarespace?

Yes. Any site that lets you add an HTML or embed block works. Paste the iframe snippet into a Custom HTML block.

Is visitor data private?

Yes. The widget generates every code with local JavaScript in the visitor's browser, so links and text are never sent to a server.

Can I resize the widget?

Yes. Change the width and height attributes in the iframe code. The widget is responsive and works from about 300 px wide upward.
