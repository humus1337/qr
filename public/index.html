Questions and answers

Are the QR codes really free?

Yes, completely free. Every code is a plain static QR code with the content baked into the image: no sign-up, no watermark, no scan limit and no expiry, and commercial use is fine. Many other QR generators watermark free codes, cap scans, or make dynamic codes expire unless you pay. Nothing here is locked behind a paywall.

Do the codes expire?

No. The code contains the content itself, so it keeps working forever. If you encoded a link, it works for as long as the site it points to exists.

Is my data uploaded anywhere?

No. Generation happens entirely in your browser. Links, Wi-Fi passwords and logos are never sent to a server.

My code does not scan. What should I check?

Keep strong contrast between the code and its background, leave a margin, do not oversize the logo, and test with a couple of phones. The scan meter under the preview flags the common problems.

Which format should I download?

For print, use SVG (sharp at any size) or PNG at 2048 px and up. For social media and websites, a regular PNG is enough.

How is this different from other free QR code generators?

It stays free the whole way through. There is no account, no watermark on your code, no scan limit, and codes never expire, and you can use them commercially. Other tools are often free to design but then watermark the download, cap scans, or charge to keep a dynamic code working. Here the QR code is static and permanently yours.
