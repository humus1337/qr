How to make a menu QR code

  1. Put your menu online. Host it as a web page, a PDF, or a shared file on Google Drive or Dropbox, and copy the link.
  2. Paste the link. Drop the menu link into the generator.
  3. Brand it. Add your restaurant colors, your logo in the center, and a Scan for menu label so it fits the table setting.
  4. Print it. Download a high-resolution PNG or SVG and print it for table tents, the window or the counter.

Update the menu without reprinting

Point the code at a link you control, such as a page on your site or a PDF you can replace. Change the dishes or prices behind that link and every printed code keeps working, because the code only carries the address, not the menu itself. Keep the link stable and you never reprint.

That is the practical difference from paid dynamic-menu services: here the code is a plain static QR that is free forever, and you host the menu wherever suits you.

Questions

Can I update the menu without reprinting the code?

Yes, as long as the link stays the same. Point the code at a page or file you control, then change the menu behind that link and the printed code keeps working.

Is there a monthly fee?

No. This makes a static QR code that is free and never expires. Many menu QR services charge every month and switch the code off if you stop paying. This one is yours to keep.

What size should I print it for a table?

For a table tent, a printed code about 3 to 5 cm wide scans easily. Download SVG or a PNG at 2048 px or larger so it stays sharp at any size.

Where do I host the menu itself?

Any public link works: your website, a PDF on your host, a Google Drive or Dropbox share, or a simple page builder. The QR code just points people to that link.
